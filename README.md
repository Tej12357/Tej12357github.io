# Tejal Vandole — Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript, ready for GitHub Pages.

## Files

- `index.html` — portfolio content
- `style.css` — responsive styling and animations
- `script.js` — mobile navigation and reveal animations
- `assets/profile.jpg` — cropped professional portrait
- `assets/Tejal_Vandole_Resume.pdf` — add your final PDF resume here

## Before publishing

1. Replace `assets/Tejal_Vandole_Resume.pdf` with your current resume.
2. Replace the email, LinkedIn and GitHub placeholders in `index.html`.
3. Replace the project placeholder links with your actual repositories.
4. Create a GitHub repository named `YOURUSERNAME.github.io`.
5. Upload all files and enable GitHub Pages from the repository settings.

The site is intentionally dependency-light so it can be hosted as a static GitHub Pages website.
